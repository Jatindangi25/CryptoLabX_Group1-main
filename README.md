# Monoalphabetic Substitution Cipher

* [ ] Select at least 1 page of plaintext from *Modern Cryptography* by Katz and Lindell.
* [ ] Store the plaintext in the program.
* [ ] Generate ciphertext using a fixed monoalphabetic substitution key.
* [ ] Display the ciphertext.
* [ ] Perform letter-frequency analysis.
* [ ] Display ciphertext letters in descending frequency order.
* [ ] Calculate percentage frequency of each letter.
* [ ] Identify the most frequent letters.
* [ ] Perform word-frequency analysis.
* [ ] Identify one-letter, two-letter, and three-letter words.
* [ ] Identify repeated words.
* [ ] Perform repeated-letter pattern analysis.
* [ ] Propose possible ciphertext → plaintext substitutions.
* [ ] Apply suspected substitutions.
* [ ] Display partial plaintext after each substitution.
* [ ] Reject incorrect substitutions and try alternatives.
* [ ] Recover meaningful plaintext.
* [ ] Recover the complete substitution key.
* [ ] Re-encrypt the recovered plaintext.
* [ ] Verify that the generated ciphertext matches the original ciphertext.
* [ ] Document the cryptanalysis decisions in the required notebook table.
* [ ] Include screenshots/output of important program results.
* [ ] Verify that all required functions are implemented:

  * [ ] `frequency_analysis()`
  * [ ] `word_frequency_analysis()`
  * [ ] `pattern_analysis()`
  * [ ] `apply_substitution()`
  * [ ] `display_partial_plaintext()`
  * [ ] `verify_solution()`
