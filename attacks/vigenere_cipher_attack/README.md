# Vigenere Cipher Cryptanalysis

## Overview

This project implements cryptanalysis of the Vigenere Cipher when the secret key is unknown.

The attack uses statistical techniques to estimate the key length, recover the key, decrypt the ciphertext, and verify the result.

## Techniques Used

- Kasiski Examination
- Index of Coincidence (IC)
- Frequency Analysis
- Chi-Square Analysis
- Vigenere Decryption
- Encryption Verification
